가설 기반 CRM 캠페인 설계·운영

배경
매출팀으로 이동해 CRM을 전담하게 되며, 설계사의 실제 행동 데이터를 근거로 가설을 세우고 검증하는 방식으로 캠페인을 설계하고자 했습니다.
활동
매달 여러 건의 가설 기반 CRM 캠페인을 직접 설계·발송·분석했습니다. 대표적으로,
— 계약체결 대기 넛지: 가계약 승인 후 미체결 상태를 감지해 자동 발송 → CTR 7~19.5%(6개 캠페인 중 최고 반응률)
— 보장분석(MEAI) 미조회 리마인드: 손실 프레이밍 메시지 → 저활동 세그먼트 특성상 CTR 0~3.3%에 그침, 카피·타이밍 개선 필요성 진단
— 등록+MEAI대화 결합 리워드 이벤트: 신규고객 849명 중 MEAI 조회 45.5%, 추가대화 32.4% 달성, ACTIVE 세그먼트에서 더 강하게 반응(49.2% vs 31.7%)
— 지점장 알림: 설계사 단일 타겟에서 설계사→지점장 2단 구조로 CRM을 확장, 컴플라이언스 제약 속에서 '전달 대상 구조'를 실험 축으로 활용
— 마감 임박 프레이밍: 동일 문구 반복 발송 시 CTR이 5.3%→1.7%로 급감하는 것을 확인
기른 역량
가설→설계→발송→분석 전체 사이클을 스스로 운영하는 캠페인 기획력, Oracle SQL로 대상군을 직접 추출하고 Tableau로 성과를 리포팅하는 데이터 역량, 컴플라이언스 제약이 큰 환경에서 실험 축을 유연하게 바꾸는 문제해결력을 길렀습니다.
회고
리소스 부족으로 같은 카피를 반복 발송했는데, 다시 한다면 문구 컨셉·강조 수치 등을 AI로 일부 수정해 여러 배리에이션을 만들어 반응률 감소를 방어했을 것 같습니다. 또한 트래킹이 어렵다는 이유로 고객 활동과 직접 연결되는 캠페인을 미뤄왔는데, 등록+MEAI 연결 캠페인을 먼저 실행해보니 비포·애프터 비교만으로도 기여도를 판단할 수 있었습니다. 필요하다고 판단되면 트래킹 요건은 이후에 IT에 요청하더라도 우선 실행부터 하는 게 맞다는 걸 배웠습니다.
임팩트
6개 캠페인 중 최고 반응률(CTR 최대 19.5%) 캠페인을 포함해 퍼널 진단의 실질적 근거 데이터를 축적했고, 설계사 CRM을 지점장까지 포함하는 2단 구조로 확장하는 설계 축을 마련했습니다.
