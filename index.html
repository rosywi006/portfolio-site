2024.06 — 2024.08

HCX 기반 수학튜터서비스 '쉬운 설명' 프롬프트 설계

배경
이해도 점수가 낮은 하위권 학생(6~7등급)도 쉬운 문제는 맞힐 수 있다는 가설 아래, 이들을 위한 '쉬운 설명'을 AI가 어떻게 생성할 수 있을지 정의가 필요했습니다.
활동
목록형 구조화, 예시 생성, 힌트 첫 단계 풀이 등 프롬프트 태스크 7종을 설계하고 GPT-4·HCX로 각각 테스트했습니다. 테스트 결과를 바탕으로 개념별 예시·반례 생성 가능 여부에 대한 분류 기준을 세워 최종 프롬프트에 반영했습니다.
기른 역량
모델 특성(GPT-4 vs HCX)을 실험으로 검증하고 한계에 맞춰 설계를 조정하는 프롬프트 엔지니어링 역량, 정성적 결과를 정량 지표로 환산해 의사결정하는 습관을 길렀습니다.
회고
테스트 문항의 문장 길이가 짧아 '문장 길이 제한' 태스크는 제대로 검증하지 못했는데, 다시 한다면 실험 초반에 문항 특성을 더 다양하게 확보해 태스크별 검증 조건을 갖추고 싶습니다.
임팩트
목록형 구조화·예시 생성·힌트 첫 단계 풀이·이것만은 알고가자·힌트 개념 맵핑 5개 태스크가 최종 프롬프트에 반영되어, 실제 수학튜터서비스의 힌트·개념 카드 생성 로직의 기반이 되었습니다.
